    苹果手机开后台

    Safari 标签页不能在你刷别的软件时弹出系统通知。必须加到主屏幕，再从图标打开（iOS 16.4 以上）。

    1. Safari 底部分享（方框加箭头）
    2.「添加到主屏幕」
    3. 回桌面点「莉莉Amour」图标打开，不要再从 Safari 进
    4. 点「开后台」，通知选允许
    5. 去刷别的时，不要从后台卡片把应用上划关掉

    苹果没有安卓那种「页面全关后仍定时唤醒」。锁屏太久、开静音、省电，或系统把应用冻住，后台就会停。这是系统限制。

    安卓手机开后台

    不要用手机自带浏览器（小米 / 华为 / OPPO / vivo / 夸克）。请用 Chrome 或 Edge 打开本站。

    1. Chrome / Edge 菜单 →「添加到主屏幕 / 安装应用」
    2. 从桌面图标打开
    3. 点「开后台」，通知选允许
    4. 系统设置 → 应用 → Chrome/Edge → 通知允许，电池选「不受限制」
    5. 不要从后台卡片划掉这个应用

    挂太久仍可能被系统杀掉。别的软件播视频/听歌时，保活也可能被打断，回到本页会自动恢复。
